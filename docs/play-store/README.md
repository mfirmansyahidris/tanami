# Tanami Play Store screenshots

Captured from the Medium Phone Android emulator running the current Tanami debug build.

- `store-ready/id/` and `store-ready/en/` contain six upload-ready phone screenshots per language.
- Upload-ready files are JPEG, 1080 × 1920 pixels (9:16).
- `id/` and `en/` retain the original 1080 × 2400 emulator captures.
- The demo garden contains one cucumber entry created on the emulator for the screenshots.

The upload-ready images are cropped from the emulator captures to meet Google Play's recommended portrait dimensions. Google Play currently recommends at least four phone screenshots at 1080 × 1920 or higher for app recommendation eligibility; the listing allows up to eight screenshots per supported device type. See [Google Play preview asset requirements](https://support.google.com/googleplay/android-developer/answer/9866151).
